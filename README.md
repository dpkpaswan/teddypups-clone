# teddypups-clone

A responsive recreation of the [TeddyPups Dubai](https://puppy.instabizweb.com/) website built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Features
- **Custom Cursor**: Whimsical dual-element cursor with spring physics, link hover states, and card peek badges.
- **Scroll Animations**: Smooth entrance reveals powered by IntersectionObserver.
- **Interactive Door Cards**: 3D swinging wooden doors revealing puppy profiles.
- **Full Catalog & Filtering**: Breed, origin, and gender query param filters on `/puppies`.
- **Dynamic Puppy Details**: `/puppies/[slug]` with interactive photo gallery, specs, and WhatsApp inquiries.
- **Static Pages**: Happy Families, How It Works, FAQ pinboard accordion, Contact letter form, and Gone Home vintage tickets.
- **Responsive & Accessible**: Desktop, tablet, and mobile views with reduced-motion compliance.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
